# Engineering-Services — Static website

This commit adds a simple static website for the Engineering Services repository. Files added:

- `index.html` — Main page with company overview
- `services.html` — List of services (design review, certification, contractual consultancy, maintenance, etc.)
- `support.html` — Customer support page with phone number +91-1234567890
- `css/styles.css` — Basic styling

To view the site locally, open `index.html` in a browser. To publish via GitHub Pages, enable Pages in repository Settings and use the `main` branch (root).
